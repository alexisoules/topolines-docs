# Figma plugin

Generate contour maps without leaving your Figma canvas.

## What it does

The plugin connects to your TopoLines account and drops generated contours straight into your file — as a **vector layer** you can restyle like any other Figma frame.

Useful when contours are one element of a larger composition (a poster, a brand board, a UI mockup) and you don't want to round-trip through the web app and a file import.

## Setup

1. Install the plugin from the Figma Community.
2. Open it in any Figma file.
3. Paste your **API key**, found in your [account page](https://www.topolines.app/app) on topolines.app.

The API key links the plugin to your account so paid features and credits work the same as on the web.

## Using it

1. Choose a location and area.
2. Adjust contour interval, stroke and colour — the same core parameters as the web editor.
3. Generate a preview.
4. Insert into your canvas as SVG (vector) or PNG.

## Notes

- **Free tier works** in the plugin too, with the same limits as the web app (PNG only, standard resolution).
- Credits are shared between the plugin and the web app — one balance.
- If the plugin appears stuck, fully reload the Figma tab. Closing the plugin window doesn't reset it: Figma keeps plugin code running in the background.
